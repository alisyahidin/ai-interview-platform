# Web test fixtures are generated from API specs, not hand-authored

F8 happened because the frontend read a response key (`required_level`, `is_override`) that the backend never sent — nobody verified the assumed shape against a real payload. To make that class of bug fail a build instead of shipping, MSW fixtures under `web/` are generated by an api rake task from real serialized payloads, not hand-written against documentation. Generated fixtures are committed to git rather than produced at web-test runtime, so web-only PRs don't need to run the api suite, keeping the path-filtered CI split fast and independent. A CI job in the api-path-filtered lane re-runs the export and diffs it against what's committed, failing the build if they've drifted. The alternative — always regenerating fixtures as part of every web CI run — was rejected because it couples every web-only change to the api suite's runtime.
